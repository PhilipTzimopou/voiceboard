# Voiceboard για Windows

Η έκδοση Windows του Voiceboard, με τις ίδιες λειτουργίες και την ίδια λογική με την έκδοση Mac (`../mac`).
Τρέχει στη γραμμή εργασιών, δίπλα στο ρολόι.

- **Κράτα Ctrl + Win** και μίλα. Μόλις αφήσεις τα πλήκτρα, το κείμενο μπαίνει εκεί όπου βρίσκεται ο κέρσορας.
  (Στο Mac: Control + Option. Το Ctrl + Win είναι και η προεπιλογή του Wispr Flow για Windows.
  Το Ctrl + Alt δεν το διαλέξαμε, γιατί στα Windows λειτουργεί σαν AltGr και γράφει σύμβολα όπως το €.)
- **Μεσαίο κλικ**: ηχογράφηση χωρίς χέρια. Με δεύτερο μεσαίο κλικ σταματά.
- **Esc**: ακύρωση.
- Μοντέλα: **Scribe v2** της ElevenLabs (με κλειδί του χρήστη) ή **Whisper large-v3** τοπικά (δωρεάν).
  Αν το Scribe αποτύχει, η εφαρμογή περνά μόνη της στο Whisper. Γλώσσα `el`.

**Εγκατάσταση για τους θεατές:** [AI-INSTALL.md](AI-INSTALL.md). Ο θεατής δίνει αυτό το αρχείο στο AI του.

## Τι έχει ελεγχθεί και τι όχι

**Δεν έχει δοκιμαστεί ακόμα από άνθρωπο σε πραγματικά Windows.** Ο κώδικας γράφτηκε σε Mac. Η λίστα στο τέλος
δείχνει τι θέλει έλεγχο με πραγματικό υπολογιστή Windows.

Τι ελέγχεται αυτόματα:

- **Σε Mac** (`dotnet test`): λεξιλόγιο και μορφή `vocabulary.json`, αντικαταστάσεις, keyterms του Scribe, αποστολή σε κομμάτια
  και ένωση κειμένου, μετατροπή ήχου 48 kHz → 16 kHz, ιστορικό και στατιστικά, εισαγωγή από βάση Wispr Flow.
  Επίσης η μεταγραφή με το Whisper large-v3 μέσω της ίδιας βιβλιοθήκης (Whisper.net) σε ελληνική φωνή.
- **Σε Windows, στο GitHub Actions** (`--self-test`, σε κάθε αλλαγή): χτίσιμο, tests, φόρτωση του Whisper και μεταγραφή
  συνθετικής φωνής, πρόχειρο με ελληνικά, επικόλληση με Ctrl+V σε πεδίο κειμένου και επαναφορά του προχείρου,
  ότι η παρακολούθηση πλήκτρων βλέπει το Ctrl + Win, ότι η ένδειξη δεν παίρνει την εστίαση, εικόνες από όλες τις σελίδες
  του παραθύρου και την ένδειξη, αθόρυβη εγκατάσταση, εκκίνηση και απεγκατάσταση. Οι εικόνες και το `results.json`
  βρίσκονται στο artifact `voiceboard-self-test` κάθε εκτέλεσης.

Τι ΔΕΝ μπορεί να ελεγχθεί αυτόματα (θέλει άνθρωπο):

- [ ] Πραγματικό μικρόφωνο: ηχογράφηση, ένδειξη έντασης, «Δεν ακούω ήχο» όταν το μικρόφωνο είναι κλειστό.
- [ ] Κράτημα Ctrl + Win με το χέρι, και ότι **δεν** ανοίγει το μενού Έναρξη όταν αφήνεις το Win.
- [ ] Μεσαίο κλικ με πραγματικό ποντίκι (ξεκινά και σταματά, δεν ανοίγει συνδέσμους στον browser εκείνη τη στιγμή).
- [ ] Esc κατά την ηχογράφηση.
- [ ] Επικόλληση σε Word, Chrome, Outlook, Slack, Notepad.
- [ ] Ένδειξη σε δύο οθόνες με διαφορετική κλίμακα (π.χ. 100% και 150%).
- [ ] Κατέβασμα του large-v3 (3,1 GB) και ταχύτητα σε υπολογιστή χωρίς κάρτα γραφικών.
- [ ] Scribe v2 με πραγματικό κλειδί, και πέρασμα στο Whisper όταν κόβεται το ίντερνετ.
- [ ] Windows 10: η βιβλιοθήκη του Whisper δηλώνει Windows 11. Στα Windows 10 μπορεί να μη φορτώνει· τότε μένει το Scribe.

## Πώς δουλεύει

| | Mac | Windows |
|---|---|---|
| Γλώσσα | Swift / AppKit | C# / .NET 10, WPF |
| Συντόμευση | `CGEvent.tapCreate` | low-level hooks (`WH_KEYBOARD_LL`, `WH_MOUSE_LL`) σε δικό τους νήμα |
| Μενού Έναρξη | δεν υπάρχει | όταν αφήνεις το Win μετά την υπαγόρευση, στέλνουμε ένα «κενό» πλήκτρο πρώτα, ώστε να μην ανοίξει |
| Εισαγωγή κειμένου | πρόχειρο → Cmd+V → επαναφορά σε 500 ms | πρόχειρο → Ctrl+V (`SendInput`) → επαναφορά σε 500 ms. Το κείμενο δεν μπαίνει στο ιστορικό προχείρου (Win + V) |
| Ένδειξη | `NSPanel` nonactivating | παράθυρο WPF με `WS_EX_NOACTIVATE`, `WS_EX_TRANSPARENT`, πάντα από πάνω, σε κάθε οθόνη |
| Μικρόφωνο | AVAudioEngine | WASAPI (NAudio) + μετατροπή σε 16 kHz με φίλτρο |
| Whisper | `whisper-server` / `whisper-cli` του Homebrew | Whisper.net μέσα στην εφαρμογή· κάρτα γραφικών με Vulkan, αλλιώς επεξεργαστής |
| Άδειες | Προσβασιμότητα + μικρόφωνο | μόνο οι ρυθμίσεις απορρήτου του μικροφώνου |
| Εγκατάσταση | `build.sh` | `VoiceboardSetup.exe` (Inno Setup), χωρίς δικαιώματα διαχειριστή |

Η λογική (κομμάτια ήχου ανά παύση 0,8 δευτ., ένωση κειμένου, λεξιλόγιο, όρια χρόνου, έλεγχος πέντε φορές το δευτερόλεπτο,
επανεκκίνηση μικροφώνου, πέρασμα από Scribe σε Whisper) είναι μεταφορά της έκδοσης Mac, με τα ίδια νούμερα.
Μία διαφορά: το Whisper στον επεξεργαστή είναι πιο αργό από το Whisper του Mac, γι' αυτό το όριο αναμονής του
είναι 30 δευτ. + διπλάσιο της διάρκειας του ήχου (τουλάχιστον 45), αντί για 45 σταθερά.

## Αρχεία

Όλα στο `%APPDATA%\Voiceboard\`:

- `config.json`: `elevenLabsAPIKey`, `whisperModel`, `language`, με τα ίδια κλειδιά με το Mac. Το κλειδί μπαίνει από τις Ρυθμίσεις.
- `settings.json`: μοντέλο, μικρόφωνο, ήχοι, ημερήσιος στόχος (στο Mac: UserDefaults).
- `vocabulary.json`: `words`, `replacements`, `snippets`, ίδια μορφή με το Mac. Αντιγράφεται αυτούσιο από Mac σε Windows.
- `history.json`, `voiceboard.log` (χρόνοι και σφάλματα, όχι το κείμενο).
- `models\ggml-large-v3.bin`: κατεβαίνει μόνο του από το Hugging Face την πρώτη φορά που επιλέγεται το Whisper.

Εισαγωγή από Wispr Flow: διαβάζει το `flow.sqlite` από το `%APPDATA%\Wispr Flow\` (ή `%LOCALAPPDATA%`).
Η θέση του αρχείου στα Windows δεν έχει επιβεβαιωθεί σε υπολογιστή με Wispr Flow.

## Κώδικας

```
src/Voiceboard.Core/     λογική χωρίς οθόνη (τρέχει και σε Mac): ρυθμίσεις, λεξιλόγιο, κομμάτια ήχου, μεταγραφή, ιστορικό
src/Voiceboard/          η εφαρμογή Windows: Controller (≈ AppDelegate), HotkeyMonitor, Paster, Recorder, Overlay, MainWindow, SelfTest
tests/                   tests της λογικής (xUnit)
installer/Voiceboard.iss το αρχείο εγκατάστασης
make-icon.py             το εικονίδιο (ίδιο σχέδιο με το make-icon.swift)
../.github/workflows/build.yml   χτίσιμο και έλεγχος σε Windows (και Mac), Release με tag
```

Χτίσιμο και tests σε Mac (για έλεγχο του κώδικα· η εφαρμογή τρέχει μόνο σε Windows):

```bash
dotnet test tests/Voiceboard.Core.Tests
dotnet build src/Voiceboard -c Release
```

Νέα έκδοση για τους θεατές: tag `voiceboard-windows-v1.0.0` και push. Το GitHub Actions φτιάχνει Release με το `VoiceboardSetup.exe`.

Το αρχείο εγκατάστασης δεν έχει ψηφιακή υπογραφή. Όποιος το κατεβάσει από browser βλέπει την προειδοποίηση του SmartScreen.
Η υπογραφή θέλει πιστοποιητικό (Azure Trusted Signing ή αγορά πιστοποιητικού), με ετήσιο κόστος.
