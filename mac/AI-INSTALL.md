# Οδηγίες εγκατάστασης του Voiceboard για Mac (για το AI σου)

> Δώσε αυτόν τον σύνδεσμο στο AI σου (π.χ. Claude Code ή Codex) και γράψε:
> «Εγκατάστησέ μου το Voiceboard για Mac ακολουθώντας αυτές τις οδηγίες».

## Για το AI: τι εγκαθιστάς

Το Voiceboard είναι δωρεάν εφαρμογή υπαγόρευσης για Mac. Ο χρήστης κρατά **Control + Option**, μιλά,
και το κείμενο γράφεται εκεί όπου βρίσκεται ο κέρσορας. Τρέχει στη γραμμή μενού (πάνω δεξιά).
Μεταγράφει με το Whisper large-v3 τοπικά (δωρεάν, χωρίς ίντερνετ) ή με το Scribe v2 της ElevenLabs (με κλειδί του χρήστη).

Η εφαρμογή χτίζεται από τον κώδικα στον υπολογιστή του χρήστη (δεν υπάρχει έτοιμο αρχείο εγκατάστασης)
και μπαίνει στο `~/Applications/Voiceboard.app`. Τα δεδομένα μένουν στο `~/Library/Application Support/Voiceboard/`.

Μίλα στον χρήστη στα ελληνικά, με απλά λόγια. Κάθε βήμα που θέλει δική του ενέργεια, πες του το ακριβώς.

### Πριν ξεκινήσεις, έλεγξε

1. macOS 14 (Sonoma) ή νεότερο: `sw_vers -productVersion`.
2. Ελεύθερος χώρος τουλάχιστον 5 GB (το μοντέλο Whisper είναι 3,1 GB): `df -h ~`.
3. Command Line Tools της Apple: `xcode-select -p`. Αν λείπουν, τρέξε `xcode-select --install` και ζήτα από τον χρήστη να πατήσει
   «Install» στο παράθυρο που θα ανοίξει. Περίμενε να τελειώσει πριν συνεχίσεις.
4. Homebrew: `command -v brew`. Αν λείπει, εγκατάστησέ το με την εντολή του https://brew.sh (ζητά τον κωδικό του Mac:
   ο χρήστης τον γράφει μόνος του στο Τερματικό).

### Βήμα 1: κατέβασε τον κώδικα

```bash
git clone https://github.com/PhilipTzimopou/voiceboard.git ~/voiceboard || git -C ~/voiceboard pull
```

### Βήμα 2: εγκατάσταση

```bash
~/voiceboard/mac/install.sh
```

Εγκαθιστά το `whisper-cpp` από το Homebrew, κατεβάζει το μοντέλο Whisper (3,1 GB, με γρήγορο ίντερνετ 5-15 λεπτά),
χτίζει την εφαρμογή και την ανοίγει. Αν το κατέβασμα διακοπεί, τρέξε ξανά την ίδια εντολή: συνεχίζει από εκεί που σταμάτησε.
Η ίδια εντολή κάνει και αναβάθμιση, χωρίς να χάνονται λεξιλόγιο, ιστορικό και κλειδί.

### Βήμα 3: άδειες

Το macOS ζητά δύο άδειες. Πες στον χρήστη:

1. **Μικρόφωνο**: στο παράθυρο που εμφανίζεται, πάτα να επιτρέπεται.
2. **Προσβασιμότητα**: χωρίς αυτήν η εφαρμογή δεν ακούει τα πλήκτρα και δεν γράφει το κείμενο. Στο παράθυρο του Voiceboard
   πάτα «Άνοιγμα ρυθμίσεων» και ενεργοποίησε το Voiceboard στη λίστα. Αν ο διακόπτης φαίνεται ήδη ανοιχτός αλλά δεν δουλεύει,
   πάτα «Επαναφορά άδειας» και ενεργοποίησέ το ξανά.

Όταν όλα είναι εντάξει, η ένδειξη κάτω αριστερά στο παράθυρο γράφει «Έτοιμο».

### Βήμα 4 (προαιρετικό): Scribe v2 της ElevenLabs

Ρώτα τον χρήστη: «Έχεις κλειδί API από την ElevenLabs;» Αν ναι, πες του να το αντιγράψει (Cmd+C) και μετά τρέξε:

```bash
~/voiceboard/mac/set-key.sh
```

Το σενάριο παίρνει το κλειδί από το πρόχειρο, ώστε να μη γραφτεί στη συνομιλία. Μην ζητήσεις από τον χρήστη να σου το επικολλήσει.
Για να το σβήσει: `~/voiceboard/mac/set-key.sh --remove`.

### Βήμα 5: πρώτη δοκιμή

Πες στον χρήστη:

1. Άνοιξε τις Σημειώσεις (Notes) και κάνε κλικ μέσα σε μια σημείωση.
2. Κράτα πατημένα **Control + Option**, πες «Γεια σου, αυτή είναι μια δοκιμή», και άφησε τα πλήκτρα.
3. Στο κάτω μέρος της οθόνης εμφανίζεται μια μικρή ένδειξη όσο ηχογραφεί. Μόλις αφήσεις τα πλήκτρα, το κείμενο γράφεται.

Άλλες συντομεύσεις: **μεσαίο κλικ** = ηχογράφηση χωρίς χέρια, ξανά μεσαίο κλικ για τέλος. **Esc** = ακύρωση.

Ο χρήστης αλλάζει τα πλήκτρα στο παράθυρο του Voiceboard, **Ρυθμίσεις → Συντομεύσεις**: Control + Option, Control + Command,
Option + Command, δεξί Option ή δεξί Command. Για τη λειτουργία χωρίς χέρια διαλέγει μεσαίο κλικ, ένα από τα πλαϊνά κουμπιά του ποντικιού ή κανένα.
Ρώτα τον χρήστη αν θέλει άλλα πλήκτρα από την προεπιλογή, π.χ. αν χρησιμοποιεί ήδη το Control + Option σε άλλη εφαρμογή.

### Αν κάτι δεν δουλεύει

| Τι βλέπει ο χρήστης | Τι κάνεις |
|---|---|
| Τίποτα δεν γίνεται με Control + Option | Λείπει η άδεια Προσβασιμότητας (βήμα 3). |
| «Δεν ακούω μικρόφωνο» | Λείπει η άδεια μικροφώνου, ή στις Ρυθμίσεις του Voiceboard είναι επιλεγμένο άλλο μικρόφωνο. |
| Ηχογραφούν δύο εφαρμογές μαζί | Είναι ανοιχτό το Wispr Flow με την ίδια συντόμευση. Κλείσ' το. |
| «Σφάλμα μεταγραφής» | Δες το αρχείο καταγραφής (παρακάτω). |

Αρχείο καταγραφής (χρόνοι και σφάλματα, όχι το κείμενο της υπαγόρευσης):

```bash
tail -40 ~/Library/Application\ Support/Voiceboard/philip-voice.log
```

### Απεγκατάσταση

```bash
pkill -x Voiceboard; rm -rf ~/Applications/Voiceboard.app
```

Τα δεδομένα (λεξιλόγιο, ιστορικό, κλειδί, μοντέλο) μένουν στο `~/Library/Application Support/Voiceboard/`.
Αν ο χρήστης θέλει να φύγουν κι αυτά, ρώτα τον πρώτα και μετά διάγραψε τον φάκελο.
